# Rosetta Stone

The Rosetta Stone is one of the most important Egyptian objects associated with the British Museum visitor experience. It is useful for demonstrating exact object lookup, historical context retrieval and source-backed answer generation.

For the production system, object records should preserve metadata such as museum number, title, object type, production date, production place, material, inscriptions, department, location and rights information.

The assistant must avoid inventing details. If a field is not present in the ingested record, the response should say that the local corpus does not contain enough evidence.
